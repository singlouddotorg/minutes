About Minutes & before you begin

Pre-release. This suite is still in testing. Feedback is welcome — please use with caution, and keep a backup of anything important. Reach the developer, Kevin of SingLoud.org, at sacredharpbiblio@gmail.com.

Use a laptop, desktop computer, or tablet with a physical keyboard — this suite isn't designed for phones. Everything runs locally and works fully offline once this page is open.

Opening a singing offers a folder browser, which needs a Chromium-based browser (Chrome, Edge, Opera) — Firefox and Safari don't support it yet, though choosing a singing file directly works everywhere regardless.

Tunebooks is a separate app for curating tunebook data itself (editions, page indexes, contributions) — most people recording a singing will never need it; this suite already ships with the tunebook data built in.

Event Details

The basic facts that head every set of minutes.

Working from a CSV that didn't come through Setup — someone emailed it to you, say? Open it in Setup (stage 1) and it becomes the singing every stage is working on.

The "Name of singing" field is the proper, stable name — e.g. "Dahlonega Shenandoah Harmony Singing" — used for the SHMHA Minutes Book export, which keeps its printed title fixed. Every other export (plain text, Markdown, HTML, the on-screen preview) bakes the number in automatically, e.g. "2nd Annual Dahlonega Shenandoah Harmony Singing" — you don't need to type it twice.

Song List

Drag rows to reorder, fix mistaken pages, and normalize leader names before export. Rows in red are missing a title or page. Use "Notes / Dedication" for inline dedications like "in memory of Buell Cobb" — they'll print right after the page number.

Sessions

More than one session showed up in your rows — from "Start New Session" in Capture, or inferred from a date change. If the singing moved to a different venue, set that session's location here; it'll be used in that session's opening sentence instead of the main Location field on Event Details, which stays the first session's venue for the header. Officers below are optional, and each has three real choices: use the Event Details / Roles default, set no one for that role this session, or name a different person for that one session only.

Book handling

Every non-default book shows its SingLoud.org tunebook Work Code next to the page number everywhere in this app, e.g. 39t (SHC) — pulled directly from the Tunebook Library, not something you assign here. Songs from the default book print with no tag. A book that's neither indexed in the Tunebook Library nor tagged "Other" shows as flagged instead, since that combination means the row's own Book value needs a look. The one exception is the dedicated SHMHA Minutes Book export on the Preview & Export tab — that format automatically translates to the Minutes Book's own abbreviations (e.g. 39t (CB)) using the table on the SHMHA Guide tab. If your rows use different Day labels, each day's default book is auto-detected from whichever book appears most that day, unless you name a default above.

SHMHA Minutes Book — Submission Guide

The Sacred Harp Musical Heritage Association's own instructions for submitting minutes, kept here for reference. The SHMHA Minutes Book export on the Preview & Export tab already applies the formatting rules below automatically — this tab is for double-checking, and for anything a rules-based export can't judge for you (brevity, verifying spellings, and so on).

How to submit
  • Name / Location / Date. Start with exactly three lines: the name of the singing, the location, and the date(s). Not all-caps.
  • Breaks. Show RECESS or LUNCH — capitalized exactly like that — on a line by themselves.
  • Multi-day singings. Start a second or third day with the day and date spelled out on its own line.
  • Names. Verify every spelling. No state names or abbreviations after a singer's name. No comma between a name and the first song number.
  • Song numbers. List songs by number only; give a title only if the song isn't in a printed book. Add lower-case "t" or "b" only when two songs start on the same page (e.g. 31t, 49b) — a song alone on its page gets no letter (306, not 306b).
  • Other singing books. Use the abbreviations on page 44 of the Minutes Book (table below) — not Work Codes.
  • Memorial lesson. For those memorialized, include state of origin and year of death if known.
  • Officers. List at the very end, ending with the secretary's name.
  • Brevity. Keep business, resolutions, reports, memorial lessons, and thanks brief — submissions are edited for space.
Plain-text style rules (the export handles these for you)
  • No bold, italics, underline, or other formatting.
  • Don't center or upper-case the title.
  • No "smart quotes" — straight quotes only.
  • Show long dashes (—) as two hyphens (--).
  • Two returns between paragraphs; two spaces between sentences.
  • Bulleted items start each paragraph with *.
